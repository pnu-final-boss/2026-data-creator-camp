8. 호출·토큰 비용을 다시 계산

정책별 trace 9,451행을 그대로 합치면 캐시 재사용을 중복 비용으로 셉니다. 고유 캐시 키 기준 5,131회이며 입력 12,853,057토큰, 출력 402,197토큰, 저장된 생성시간 합계는 약 4시간 25분입니다. 세 정책이 초기 분류와 근거를 공유한 효과는 이미 반영돼 있습니다.

형식 수정 호출은 1,072회로 고유 호출의 20.9%입니다. 유효해진 응답은 247회(23.0%)이며, 특히 행동 수정은 696회 중 47회(6.8%)만 회복됐습니다. 따라서 반복 행동을 계속 다시 생성시키는 것보다, 이미 받은 관측을 살려 종료·최종 판정을 결정하는 코드 수정이 우선입니다. 이 비용은 로컬 공개 모델의 토큰 처리량이며 유료 API 요금이 아닙니다.

9. 다음 수정의 우선순위 — 이번에는 실행하지 않음

  1. 반복 도구 요청을 종료 조건으로 처리: 이미 확보한 관측을 유지하고 최종 분류로 넘어가도록 설계합니다. 같은 읽기 작업을 재실행하거나 유효한 관측을 버리지 않습니다.
  2. 줄 범위는 실행기가 안전하게 결정: 모델에는 시작점/검토 대상을 선택하게 하고, 길이 제한·경계·페이지 분할은 코드에서 다룹니다. 조용히 의미를 바꾸는 잘라내기는 피합니다.
  3. 출력 계약을 단순화: 서로 길이를 맞춰야 하는 3개 병렬 배열 대신 라벨별 고정 레코드나 스키마 제한 생성을 검토합니다. 값·줄 번호를 임의 보충해 통과시키지 않습니다. EXAONE는 포장 제거만으로 0/16회 복구됐으므로 내부 구조 개선이 우선입니다. 문법상 유효성과 의미상 정답은 별도로 평가합니다.
  4. 현재 통계 이득을 분해: 고정 빈도/unknown 음성 억제 대조군을 유지하고, 어휘 모델의 추가 이득과 고열 이외 라벨을 확인합니다. LDA·군집 추가는 이 대조군을 넘어서는지 검증하는 후속 후보입니다.
  5. 재개 전 운영 조건: 같은 오류를 반복하지 않는 실제 소수 통화의 전체 ReAct 경로를 확인하고, 실패율 기준을 통과한 뒤 더 큰 비교를 진행합니다. 실패 모델을 전체 순차 작업과 격리하고 완료 모델의 분석은 별도로 저장하도록 바꿀 필요가 있습니다.
