# Mission 3: 통화 전사문 기반 증상 분류 실험 정리

## 목적

119 통화 전사문에서 9개 증상의 유무를 예측하고, 하나의 공유 모델과 증상별 독립 이진분류 전문가 모델을 비교했다. 대상 증상은 고열, 구토, 두통, 복통, 어지러움, 열상, 오심, 전신쇠약, 호흡곤란이다. 한 통화에 여러 증상이 함께 있을 수 있으므로 다중 레이블 분류로 구성했다.

## 학습 방법

- 사전학습된 한국어 언어모델 `klue/roberta-base`를 통화 전사문 분류에 미세조정했다.
- GPT·Gemini 등 생성형 LLM 또는 외부 LLM API는 사용하지 않았다.
- 입력에는 통화 전사문 텍스트만 사용했으며, 정답 증상과 화자 정보는 입력 특징으로 사용하지 않았다.
- 공유 모델은 하나의 인코더로 9개 증상의 있음/없음을 각각 예측한다.
- 전문가 전담 방식은 증상별 독립 이진분류 모델 9개를 구성해 결과를 결합한다. 실제 추론은 GPU 메모리 제약을 고려해 모델별로 순차 실행했다.

### 비교 방식

| 방식 | 구성 |
|---|---|
| 공유 모델 | 하나의 인코더가 9개 증상의 유무를 예측 |
| 선택형 조합 | 증상별로 공유 모델과 해당 전문가 중 calibration 성능이 높은 모델 선택 |
| 전문가 9개 전담 | 증상별 독립 이진분류 모델의 결과를 결합 |

### 주요 설정

| 항목 | 설정 |
|---|---|
| 학습률 | `2e-5` |
| 최대 에포크 | 3 |
| 최대 입력 길이 | 512 토큰 |
| 손실 함수 | 가중치 없는 Binary Cross-Entropy |
| 체크포인트 선택 | `select`의 임계값 0.5 기준 F1 |
| 최종 임계값 결정 | `calibration`에서 증상별 조정 |

## 데이터 분할

제공된 Training 데이터 29,200통을 아래와 같이 분할했다. 공식 Validation은 사용하지 않았다.

| 분할 | 통화 수 | 용도 |
|---|---:|---|
| train | 21,001 | 모델 학습 |
| select | 2,711 | 최적 에포크 선택 |
| calibration | 2,568 | 임계값 및 선택형 조합 결정 |
| holdout | 2,920 | 내부 성능 평가 |

## 내부 평가 결과

평가 지표는 9개 증상별 F1을 동일한 비중으로 평균한 Macro-F1이다. 단순 통화 정답률과는 다르다.

| 방식 | Holdout Macro-F1 |
|---|---:|
| **공유 모델** | **0.6365** |
| 선택형 조합 | 0.6341 |
| 전문가 9개 전담 | 0.6327 |

전문가 9개 전담은 공유 모델보다 0.0038 낮았다. 일부 증상에서 전문가는 소폭 개선됐지만, 전체 평균 성능 향상으로 이어지지 않았다.

### 증상별 F1

| 증상 | 공유 모델 | 선택형 조합 | 전문가 전담 | 전문가 - 공유 |
|---|---:|---:|---:|---:|
| 고열 | 0.6460 | 0.6460 | 0.6404 | -0.0056 |
| 구토 | 0.5391 | 0.5391 | 0.5353 | -0.0038 |
| 두통 | 0.5540 | 0.5562 | 0.5562 | +0.0021 |
| 복통 | 0.7953 | 0.7953 | 0.8000 | +0.0047 |
| 어지러움 | 0.6639 | 0.6639 | 0.6646 | +0.0007 |
| 열상 | 0.8822 | 0.8822 | 0.8705 | -0.0117 |
| 오심 | 0.3490 | 0.3404 | 0.3404 | -0.0086 |
| 전신쇠약 | 0.6120 | 0.5974 | 0.5974 | -0.0146 |
| 호흡곤란 | 0.6866 | 0.6866 | 0.6892 | +0.0026 |

선택형 조합은 두통·오심·전신쇠약에 전문가를 사용했다. 두통의 작은 개선보다 오심·전신쇠약의 하락이 커서 공유 모델보다 전체 점수가 낮았다. 오심은 공유 모델과 전문가 모두에서 가장 취약한 증상이었다.

## 에포크별 관찰

모델별 학습 기록을 확인한 결과, 모든 전문가가 학습 부족 상태라고 보기는 어려웠다.

- 공유 모델은 2에서 3에포크로 갈 때 개발 F1 개선이 매우 작고 개발 loss는 소폭 상승했다.
- 구토, 열상, 전신쇠약, 호흡곤란 전문가는 2에포크 모델이 선택됐다.
- 전신쇠약 전문가는 학습 loss가 감소하는 동안 개발 loss가 상승하고 F1이 정체되어 과적합 가능성을 보였다.
- 오심 전문가는 3에포크까지 개발 F1이 상승해 추가 에포크 실험을 검토할 근거가 있었다.

## 오분류 분석

저장된 정답과 예측을 통화 ID로 연결해 증상별 오탐과 누락을 조회할 수 있도록 구성했다.

| 구분 | 의미 |
|---|---|
| 오탐 | 라벨에는 증상이 없지만 모델은 있다고 예측 |
| 누락 | 라벨에는 증상이 있지만 모델은 없다고 예측 |
| 공유만 정답 | 공유 모델은 맞히고 전문가는 틀림 |
| 전문가만 정답 | 전문가는 맞히고 공유 모델은 틀림 |

오심의 calibration 분석에서는 전문가 오탐 350건, 전문가 누락 153건이 확인됐다. 이는 저장된 라벨 기준의 오류이며, 전사문 검토 전에는 모델의 혼동인지 라벨 누락인지 단정할 수 없다.

## 결론 및 다음 단계

현재 설정에서는 공유 모델이 가장 높은 내부 Macro-F1을 기록했다. 이번 결과는 전문가 방식이 일반적으로 불리하다는 뜻이 아니라, 현재 데이터·학습 설정·선택 규칙에서는 독립 전문가로 나누는 이점이 전체 성능으로 나타나지 않았다는 의미다.

다음 단계는 오심과 전신쇠약의 오분류 전사문·라벨 검토, 입력 길이 절단 여부 확인, 개발 데이터에서 학습률·에포크·임계값 비교, 다른 시드 반복 실험이다. 설정을 확정한 뒤에는 학습·개발 데이터와 겹치지 않는 별도 테스트셋으로 최종 평가한다.
